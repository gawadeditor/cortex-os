# PROJECT_NORTH_STAR.md

# Cortex

Version: 1.0
Status: Canonical
Authority: Highest

---

# Vision

Cortex is an autonomous AI operating platform capable of creating, managing, publishing, analyzing, and continuously improving digital media products without requiring human operation during normal execution.

Cortex is not a YouTube automation tool.

Cortex is not a workflow builder.

Cortex is not a collection of AI agents.

Cortex is an Operating System for autonomous media organizations.

---

# Mission

Transform content production from a manual creative workflow into an autonomous operating system capable of running one or more digital media businesses.

A human defines goals.

Cortex determines execution.

---

# Long-Term Goal

A single Cortex instance should be capable of operating multiple independent media brands simultaneously while maintaining complete isolation between them.

Examples:

- Hypogeum
- Science Channel
- Finance Channel
- Automotive Channel
- Documentary Studio
- News Organization

Each behaves as an independent business.

---

# Core Philosophy

The Factory knows HOW.

The Channel knows WHAT.

The Factory contains intelligence.

The Channel contains identity.

Neither owns the responsibility of the other.

---

# Product Layers

Layer 1

Cortex Core

The operating system.

Responsible for:

- Runtime
- Scheduling
- Orchestration
- Agent execution
- Queue management
- Skills
- Providers
- Infrastructure
- Cost optimization
- Learning engine
- Storage
- Monitoring

Contains ZERO channel knowledge.

---

Layer 2

Channel Package

Represents one business.

Contains:

- Identity
- Mission
- Audience
- Brand
- Editorial DNA
- Visual DNA
- Thumbnail DNA
- Publishing strategy
- Platform configuration
- Analytics history
- Learning
- Objectives
- Secrets

Every channel exists only as a package.

---

Layer 3

Execution

The runtime loads:

Core

+

One Channel Package

↓

Creates a temporary execution context

↓

Executes work

↓

Discards runtime state

Persistent knowledge is written back only to approved storage.

---

Layer 4

Dashboard

The Dashboard is NOT the system.

The Dashboard is an operational interface.

Its responsibilities:

- Observe
- Configure
- Approve (when required)
- Visualize
- Diagnose

The Dashboard must never contain business logic.

# Autonomous Principle

Normal operation requires no human intervention.

Humans interact only to:

- Define objectives
- Configure channels
- Review exceptions
- Approve high-risk actions
- Improve the platform

Everything else should execute automatically.

---

# Multi-Channel Principle

Every channel is isolated.

No channel:

- shares memory
- shares prompts
- shares analytics
- shares branding
- shares learning

unless explicitly configured.

---

# Learning Principle

Two independent learning systems exist.

Factory Learning

Improves Cortex itself.

Examples:

- Provider quality
- Cost optimization
- Failure patterns
- Runtime stability
- Prompt/provider compatibility
- Infrastructure decisions

This learning benefits every channel.

---

Channel Learning

Improves only one channel.

Examples:

- Audience behavior
- Retention
- CTR
- Topic performance
- Thumbnail success
- Script quality
- Publishing schedule

This learning never leaves the channel package.

---

# Decision Principle

Every autonomous decision must be evidence-based.

The system never changes strategy because of intuition.

Every optimization must be supported by measurable evidence.

---

# Safety Principle

When uncertainty may produce public mistakes,

Cortex must fail closed.

Never fail open.

Examples:

- Publishing privacy
- OAuth credentials
- Platform permissions
- Financial limits
- Destructive operations

---

# Cost Principle

Always achieve the required quality using the minimum total cost.

Optimization targets include:

- API costs
- GPU usage
- Runtime
- Storage
- Human intervention

---

# Quality Principle

Completion is not success.

Publishing is not success.

Views are not success.

Success is measured by sustained improvement of measurable outcomes over time.

---

# Success Definition

Cortex succeeds when:

- It operates continuously.
- It requires minimal human intervention.
- It learns from every execution.
- It improves over time.
- It scales across unlimited channels.
- It remains platform-independent.
- Every channel behaves like an autonomous business.

---

# First Production Target

Hypogeum

Hypogeum is the first production Channel Package used to validate Cortex.

It is NOT part of Cortex.

It is the first real-world deployment of Cortex.
