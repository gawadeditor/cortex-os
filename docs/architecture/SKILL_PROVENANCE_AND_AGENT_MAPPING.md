## 5. Installation Policy

The following is a hard rule for all future skill-related work in this repository, per `PROJECT_PRINCIPLES.md` §10 ("Never Trust Assumptions") and this repo's `CURRENT_PHASE.md` gate on Skill redesign work:

1. **Claude must never recreate, paraphrase, or imitate an upstream skill.** If a skill is meant to represent a real external product/provider/tool, its content must come from that source verbatim (or via the source's own official install mechanism), never from training-data memory of what such a skill "probably" contains.
2. **If an upstream URL is missing, the skill is BLOCKED.** No file may be created under that skill's name until a real source is obtained. This applies in particular to the six skills already named in `SKILLS_AND_AGENTS_AUDIT.md` §6 as unsourced: Humanizer, Seedance2, GPT Image2, Veo Prompt Director, Veo Tools, UI/UX Pro Max.
3. **Installation must be from the original repository/source only** — official install command (e.g. `graphify install`, a marketplace add, a documented `git clone` of the skill's own repo), never a hand-typed reconstruction based on the skill's description or reputation.
4. **Any adaptation must be a thin config/wrapper, not a rewritten skill.** If an installed upstream skill needs project-specific glue (e.g. a path constant, a model override), that glue lives in a separate wrapper file or registry entry (as `hypogeum/skill_registry.py` already does for internal skills) — the upstream skill's own content is never edited in place.
