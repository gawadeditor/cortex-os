# PROJECT PRINCIPLES

These principles override every suggestion.

## 1. Factory First

The factory is the product.
Episodes are validation only.

---

## 2. Quality Before Automation

Automation is forbidden until manual production consistently passes QA.

---

## 3. Architecture Before Features

Never add features before stabilizing architecture.

---

## 4. Manual Validation First

Every major subsystem must pass manual validation before autonomous execution.

Examples:
- Script
- Visual Package
- Thumbnail
- Video Generation
- Voice
- Assembly

---

## 5. Runtime Is Not A Milestone

Runtime is only an execution layer.

It must never become the project's primary objective.

---

## 6. Dashboard Exists To Operate The Factory

Dashboard work begins only after the production architecture is stable.

---

## 7. Every Improvement Must Increase One Of

- Quality
- Stability
- Repeatability
- Cost efficiency
- Token efficiency
- Maintainability

If not, reject it.

---

## 8. Temporary Solutions Must Be Removed

No permanent hacks.

Everything temporary becomes technical debt.

---

## 9. Every AI Decision Must Be Measurable

No subjective improvements.

Every change should be validated by measurable output.

---

## 10. Never Trust Assumptions

Read the code.

Read the architecture.

Read the documentation.

Then decide.

Never guess.
