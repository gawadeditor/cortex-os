{# ── Worker Controls ── #}
Worker Process
▶ Start Worker — runs the continuous loop (60 s interval); auto-picks queued jobs.
⏹ Stop Worker — sends SIGTERM + sets stop flag; worker finishes current job then exits.
▶ Run Once — claims exactly one queued job now (bypass scheduler); exits when done.
{# ── Queue Controls ── #}
Queue
⏸ Pause Queue — worker skips claiming new jobs; active run continues.
▶ Resume Queue — restore normal job claiming.
